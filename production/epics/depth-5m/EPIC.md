# Epic: DEPTH 5m

**Goal**: 평온하고 아름다운 꿈속 수영장을 걷다가 서서히 악몽으로 변해가는, 점프 스케어 없는 드림코어 서브틀 호러.

**Scope** (from `design/game-brief.md` MVP):
1. 밝고 몽환적인 노을/새벽빛 야외 수영장 도입부
2. 자유 이동 중 의식을 잃는 연출
3. 실내 수영장 복도에서 눈을 뜨는 연출
4. 기존 이상현상 관찰 플레이 (첫 번째 꿈 — 기존 시스템 재사용, 수정 없음)
5. 수심 1m의 가짜 엔딩
6. 플레이어를 바라보는 마네킹
7. 마네킹의 짧은 직선 돌진
8. 화면 전환 (노이즈 증가 → 암전 → 눈뜨기)
9. 기존 복도와 다른 두 번째 꿈 공간 (소규모, 기존 에셋 재사용)
10. 두 번째 공간을 잠시 관찰한 뒤 종료

**Build order**: see `design/game-brief.md` §"Build order" — stories below follow it.
