> 작성 2026-11-18. 그레이박스 더미를 실제 모델로 바꾸기 위한 목록이다.
> **이 문서만 읽고도** 다른 사람(또는 다른 Claude)이 같은 아트 스타일로 이미지와 3D 모델을 뽑을 수 있게 쓴다.

## 1. 게임 한 줄과 분위기

설정(말하지 않는 가벼운 이야기): **수영장 깊은 곳에 가라앉은 "나"가 깨어나기 전까지 꾸는 꿈.** 플라밍고 튜브와 물의 흔적이 방마다 작게 되풀이된다(기획서 §1-1).

평온하고 아름다운 꿈속 수영장을 걷다가 방을 지날수록 조금씩 어긋나는, 점프 스케어 없는 **드림코어·위어드코어 서브틀 호러**. 사람은 아무도 없다. 무서움은 "놀래킴"이 아니라 **익숙한 물건이 조금 틀린 것을 알아차리는 것**에서 나온다.

동선: 인트로 야외 수영장 → 수영장 홀 → 금 간 복도 → 잠긴 샤워실 → 노란 방 → 밤의 거실 → 파란 침실(+파란 복도) → 컴퓨터 속 → 천사 방 → 하늘 계단 → 마지막 수영장.

## 2. 아트 스타일 규칙 (모든 오브젝트 공통)

### 2-1. 한마디로
**"1990~2000년대 평범한 물건을, 꿈에서 본 것처럼 깨끗하고 조금 장난감 같게."**
사실적인 비율과 재질을 따르되, 디테일은 줄이고 형태는 또렷하게. 낡았지만 더럽지 않다.

### 2-2. 지킬 것
- **형태:** 실루엣이 또렷한 단순한 형태. 작은 장식, 나사, 글자 같은 잔디테일은 생략한다. 모서리는 살짝 둥글게(베벨).
- **재질:** 무광 위주. 칠한 나무, 무광 플라스틱, 도자기 타일, 천, 크롬은 거울처럼 말고 부드러운 반사. 젖은 느낌은 샤워실·수영장 물건만.
- **색:** 한 물건에 색 2~3개. 채도는 "바랜 듯 맑게"(파스텔~중간 채도). 방마다 정한 색감(§3 각 방 첫 줄)을 따른다.
- **낡음:** 살짝 바랜 색, 모서리 닳음 정도. 녹, 피, 곰팡이, 깨진 유리, 낙서는 넣지 않는다.
- **시대감:** 1990~2000년대 가정·공공시설 물건(브라운관, 다이얼 전화기, 베이지 컴퓨터, 플라스틱 접이식 의자).
- **사람 형체:** 마네킹·인외·이불 속 사람 등은 **얼굴이 없다**(매끈한 면). 표정, 피, 상처 없음.

### 2-3. 하지 말 것
- 실제 브랜드 로고, 상표, 간판, 실제 운영체제 로고나 화면 그대로(비슷한 "느낌"만)
- 읽을 수 있는 글자(필요하면 판독 불가한 네모 줄로)
- 다른 게임의 캐릭터·맵·에셋을 닮게 만들기(분위기와 장치만 빌린다)
- 고어, 점프 스케어용 괴물 얼굴, 과장된 호러 소품(해골, 칼, 피 묻은 것)
- 만화풍 외곽선, 셀 셰이딩, 로우폴리 각진 스타일, 극사실 스캔 질감

### 2-4. 이미지 생성 프롬프트 틀 (GPT 이미지 → VARCO 3D용)
3D 변환이 잘 되도록 **한 장에 물건 하나, 전체가 다 보이게** 뽑는다.

```
A single [오브젝트 영문 설명], dreamcore / liminal space aesthetic,
clean simplified realistic style, slightly toy-like proportions, soft rounded bevels,
matte materials ([재질]), muted faded colors ([색 2~3개]),
1990s everyday object, no text, no logos, no brand marks,
isolated on a plain light grey background, full object visible, centered,
3/4 front view from slightly above, soft even studio lighting, no harsh shadows,
no other objects, no people, product render, high detail silhouette
```

- 사람 형체일 때 덧붙임: `faceless smooth head, no facial features, neutral pose`
- 바뀌는 물건(상태 둘)은 **같은 프롬프트로 두 장**(§3에 "상태 A/B"로 적음). 크기·방향을 맞춘다.
- 판, 그림, 화면 속 내용(포스터, 창 화면, 수심 표지)은 3D가 아니라 **정면 텍스처 한 장**으로 뽑는다:
  `flat front view, orthographic, texture sheet, no perspective, no background`

### 2-5. 3D 결과물 납품 규칙 (Unity에 그대로 넣기 위해)
- 형식: FBX 또는 GLB. 단위 1 = 1m, Y가 위, **앞면은 +Z**.
- **원점(피벗)은 바닥 가운데**(떠 있는 물건은 몸통 가운데). 벽에 붙는 물건은 벽에 닿는 면 가운데.
- 크기는 §3 표의 대략 크기에 맞춘다(±10%).
- 폴리곤: 작은 소품 1~5천, 가구 5천~1.5만, 큰 것(거대 모니터, 천사) 3만 이하.
- 텍스처: PBR(Base Color, Normal, Mask/Roughness) 1K, 큰 것 2K. HDRP Lit 기준.
- **움직이는 부분은 따로 나눈 메시**(이름으로 구분): 문짝(경첩 축에 피벗), 눈알, 눈꺼풀, 머리(마네킹 `Head`), TV·모니터 화면 면(렌더 텍스처를 입힘).
- 이름: `VAR_<방>_<오브젝트>` (예: `VAR_Bedroom_Bed`, `VAR_Angel_WingedEye`). 저장 위치 `Assets/Art/Models/<방>/`.
- 그레이박스 더미 자리(아래 표의 "더미 경로")와 같은 위치·방향으로 바꿔 넣는다. 더미는 지우지 말고 끈다.

## 4. 만드는 순서 추천
1. **찾기(이상한 점) 오브젝트**: 플레이 감각에 바로 영향이 크다. 마네킹 → 날개 달린 눈 → 삐에로 인형 → 이불 속 사람 → 브라운관 TV → 거대한 모니터 → 인외.
2. **A 오브젝트**: 방이 비어 보이지 않게 하는 큰 가구와 상징물(플라밍고, 소파, 침대, 사물함 등).
3. **B 오브젝트**와 텍스처(표지, 포스터, 창 화면).
