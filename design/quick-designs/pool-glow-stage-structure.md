# Quick Design — 본편 3스테이지 구조 (Pool Glow식 탐험)

**상태**: 초안 (2026-11-11). 미정 항목은 맨 아래 "열린 질문" 참고.
**관련**: `design/game-brief.md`, 메모리 `depth5m-visual-reference-pool-glow`,
`depth5m-stabilization-vs-expansion-scope`, `depth5m-poolglow-technical-plan`

## 결정 사항 (사용자 확정 2026-11-11)
- 방향은 Pool Glow: 큰 공간을 걸으며 구경하고, 물건을 주우면 다음 스테이지로 넘어간다.
- 복도(8번 출구식 이상현상, `Scene_Game`/`AnomalyManager`)는 본편에서 빼서 **별도 모드로 보존**한다.
- 본편 데모는 **3스테이지**.
- 공포는 노이즈와 이상한 존재로 "살짝 악몽" 정도만. 점프스케어 없음.

## 규칙
- 각 스테이지는 큰 공간 하나, 끝에 발광 구체(열쇠 아이템). 줍기 → 문 열림 → 다음 스테이지.
- 한 방향 진행, 되돌아가는 경로 없음.
- 이상현상 판정/수심 시스템은 본편에서 사용하지 않는다.

## 스테이지

| | 스테이지 1 | 스테이지 2 | 스테이지 3 |
|---|---|---|---|
| 공간 | 야외 수영장 중정 (`Scene_Intro` 확장) | 실내 Pool Hall, 타일 모듈 반복의 큰 복합 홀 | 스테이지 2가 다른 모양으로 이어지는 최심부 |
| 분위기 | 따뜻한 새벽빛, 분홍 안개 | 차가운 회청색, 밝지만 끝이 안 보임 | 같은 타일 톤인데 색/스케일이 어긋남 |
| 노이즈 | 거의 없음 | 가까운 존재가 있을 때만 | 상시, 단계적 상승 |
| 이상한 존재 | 아주 멀리 선 실루엣 1개 | 기둥의 비정상 반복, 마네킹 | 새 괴물(VARCO로 나중에 생성, 지금은 마네킹 자리표시) |
| 목표 | 반대편 구체 | 마른 수영장 너머 구체 | 마지막 구체 → 데모 종료 |

## 재사용 / 신규
- 재사용: E키 상호작용, `DreamTransitionController`, `ScreenNoiseController`, 페이드,
  Visual Polish 결과(타일, 물, 안개, Volume, 그림자).
- 신규: `Collectible`(줍기), `ProgressGate`(문 열림), 스테이지 연결, 큰 맵, 스테이지별 노이즈 값.

## 맵을 키울 때 주의
- 성능 여유는 있으나(에디터 약 400 FPS) 그림자 거리/안개 거리를 같이 조정.
- 큰 맵은 비어 보이기 쉬움 → 목표물을 멀리서도 보이게, 빛/소리로 방향 유도.
- 타일/소품은 모듈 프리팹으로 만들어 반복(스테이지 확장 용이).

## 선행 조건
- Visual Polish 마무리(Play 확인: 사다리/E키/눈꺼풀, FPS) 후 안정판으로 묶는다.
- 기존 Visual Polish 지시서의 8단계 검증 흐름(복도, 마네킹, 데모 종료 패널)은
  이 구조가 정해지면 새 흐름에 맞게 다시 쓴다.

## 열린 질문 (나중에 채움)
1. 스테이지 2·3의 공간 구성 (위 안으로 갈지, 실내 정원/타일 복도 미로 등으로 바꿀지)
2. 열쇠 아이템이 발광 구체로 확정인지
3. 스테이지 간 전환 연출을 꿈 전환 하나로 통일할지, 스테이지별로 다르게 할지
4. 복도 별도 모드의 진입 방법 (메인 메뉴 항목 등 — 메인 메뉴 작업 때 결정)
